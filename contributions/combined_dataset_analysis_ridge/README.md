# Combined Dataset Analysis and Ridge Regression

This package presents combined hydroclimatic exploratory analysis and a retrospective one-month Ridge regression baseline using `aligned_0.5deg.nc`. It contains computed results, analysis code, fitted parameters, forecasts, figures, and verification records.

## Analysis notebook

Open `Combined_Dataset_Analysis_Ridge.ipynb` for the method, findings, embedded figures, and rerun instructions. Results were generated by `scripts/combined_ridge.py` and are documented in `execution.log`. The notebook presents the saved tables and figures with methods, interpretation, and reproduction code.

## Objective

Characterize the joint distributions and temporal relationships of GRACE/GRACE-FO terrestrial water storage, IMERG precipitation, and MERRA-2 temperature, and evaluate regularized linear prediction of next-month water storage. A separate Ridge model is fitted at each retained grid cell.

## Experimental design

- Grid: 0.5 degrees, 60°S to 60°N, using the upstream retained-land mask; 46,497 cells.
- Train: January 2019–December 2022. Validation: January–December 2023.
- Test: January 2024–September 2025, because the combined file ends in September. October–December 2025 are unavailable.
- Common evaluation set: 21 months × 46,497 cells = 976,437 observations for every model.
- Predictors: previous-month water storage, rainfall, and temperature; previous 3- and 12-month rainfall totals; calendar-month sine/cosine; elapsed time.
- All observed predictors end at the previous calendar month. This is retrospective one-month prediction with updated observations, not an operational forecast accounting for NASA publication delays.
- Alpha candidates: 0.1, 1, 10, 100, 1000. Validation chose **10**, with pooled validation RMSE **4.690 cm**. Scaling and coefficients were then refitted on 2019–2023.

## Findings

| Model | MAE (cm) | Pooled RMSE (cm) | Mean temporal correlation |
|---|---:|---:|---:|
| Seasonal persistence | 2.336 | 3.569 | 0.795 |
| Ridge | 3.060 | 4.709 | 0.809 |
| Persistence | 3.464 | 5.760 | 0.740 |
| Monthly climatology | 5.928 | 9.124 | 0.597 |

Ridge improves pooled RMSE by **18.24%** and MAE by **11.66%** over ordinary persistence. However, Ridge's pooled RMSE is **31.95% higher** than seasonal persistence. It tracks the direction of fluctuations slightly better on average (higher correlation), while seasonal persistence makes smaller absolute errors. The measured conclusion is that Ridge beats ordinary persistence but does not beat the stronger seasonal reference. These comparisons alone do not isolate the added value of rainfall and temperature; that would require an otherwise identical Ridge model without those inputs.

Ordinary persistence says "next month equals this month." Seasonal persistence adds the typical month-to-month seasonal change to the latest observed value. Monthly climatology predicts the historical average for that calendar month.

### Correlations

These are area-weighted averages of correlations calculated through time separately at each cell, using training months only. They are not correlations between globally pooled values.

| Relationship | Raw measurements | Training seasonal cycle removed |
|---|---:|---:|
| Water storage and rainfall | 0.183 | 0.152 |
| Water storage and temperature | -0.255 | -0.235 |
| Rainfall and temperature | 0.123 | -0.194 |

Water storage has a weak positive average relationship with rainfall and a negative relationship with temperature. Rainfall and temperature switch sign after seasonal adjustment, showing why seasonal patterns matter. The figures summarize many regions; local relationships vary. These descriptive correlations do not establish causation or statistical significance, and long-term trends have not been removed.

### Distributions

Rainfall is strongly right-skewed: many dry/light-rainfall observations and fewer very wet observations. During training, its area-weighted median is **36.78 mm/month**, below its mean of **74.59 mm/month**. Temperature spans a broad mix of climates.

The pooled water-storage distribution broadens: its standard deviation is **18.98 cm** in training versus **22.90 cm** in testing, and the 5th–95th percentile interval expands from approximately **[-26.00, 24.14]** to **[-29.96, 27.94] cm**. These are descriptive differences across locations and months, not a significance test or proof of a climate trend. The test set has unequal representation of calendar months (January–September twice, October–December once), so raw split comparisons mix seasonal composition with changes over time. Extreme values are retained, not silently clipped.

## Metric aggregation

For group comparison, use `per_cell_test_metrics.csv`: temporal MAE and RMSE are calculated within each cell, then averaged with cosine-latitude weights. The pipeline exports this table automatically. `scripts/score_saved_predictions.py` reproduces it from the archived prediction file. Alpha selection continues to use pooled validation RMSE; this is documented separately from the test-reporting convention.

The archived test results cover January 2024–September 2025 and 46,497 retained cells. The persistence results on main at commit `a388ee9` cover 24 test months and 46,325 cells. Equal latitude bounds do not establish an identical evaluation mask. Direct cross-contribution comparisons still require the intersection of valid dates and geographic cells.

The primary RMSE is the square root of pooled area-weighted squared errors over the common cell-month evaluation set. `alternative_rmse_aggregation.csv` instead reports area-weighted means of per-cell temporal RMSE: Ridge **3.670**, persistence **4.228**, seasonal persistence **2.942**, and climatology **6.707 cm**. These conventions are not interchangeable. Model comparisons require consistent aggregation, evaluation masks, test dates, and predictor availability.

The original 1.2 GB aligned dataset is not duplicated here. Its SHA-256 is recorded in the manifest.

GitHub contains the notebook, source code, tables, and figures. The binary prediction, model, and correlation archives are distributed in the complete analysis ZIP and are also regenerated by the analysis command. The saved-prediction scoring command requires `test_predictions.nc` from that archive or a reproduced run.

## Reproduce

Place the original `aligned_0.5deg.nc` beside the notebook. From the package directory with Python 3.10+:

```bash
python -m pip install -r requirements.txt
python scripts/combined_ridge.py --input aligned_0.5deg.nc --config configs/grace_fo_config.yaml --output-dir rerun_results
python -m unittest discover -s tests -v
```

`python scripts/plot_results.py` recreates the two presentation figures from the saved CSVs in this package. The original three plots are generated by the analysis script itself. Each cell's stored Ridge forecast can be reconstructed with `((X - scaler_mean) / scaler_scale) @ coefficient + intercept`.

## Checks and limits

The updated contribution suite passes 10 tests, including geographic filtering and a hand-calculated per-cell RMSE example with unequal valid month counts. The previously recorded execution and verification logs describe the original analysis run. The new `per_cell_test_metrics.csv` was recomputed from its float32 archived predictions; model fitting was not repeated for this reporting change.

All 15 synthetic regression tests passed before the real run. After the run, all four model metrics were independently reproduced with the repository's persistence evaluator. Archived model parameters reproduced test forecasts at 12 distributed cells. All models were scored on the same mask with finite predictions.

GRACE's effective measurement resolution is much coarser than its 0.5° display grid, so cells are not independent. TWS includes groundwater, soil water, surface water, snow, and ice; it is not a groundwater-only measurement. The inherited mask used full-record coverage, so spatial eligibility is not strictly prospective. Generalization to unseen regions, statistical significance of performance differences, and uncertainty calibration were not evaluated.

Source product release identifiers and original acquisition dates were not supplied with the aligned file. The manifest records the exact input checksum. The configured October–December 2025 test months are unavailable and excluded.
